# Studenthub 🎓

A comprehensive student portal application designed to manage student profiles, academic records, and collaboration.

## 🛠️ Tech Stack
* **Language:** Java
* **Framework:** Spring Boot
* **Frontend:** HTML, CSS

## ✨ Features
* User authentication and role management.
* Student profile viewing and updating.
* Course management system.
